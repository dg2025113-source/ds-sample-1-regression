# 11차시 기록: 나이 추가·비교 기준 바로잡기·후보 모델 비교

## 10101 홍길동
- 오늘 결정한 것: 해석 초안을 썼다. "몸값은 종합 능력치만으로는 설명되지 않고, 나이를 함께 봐야 한다."
- AI에게 보낸 프롬프트(원문): 모델 C에서 종합 능력치 계수는 0.0797, 나이 계수는 -0.0391이고 몸값에는 로그(밑 10)를 씌웠어. 이 숫자를 "몇 배"로 바꿔서 고등학생이 이해할 수 있게 설명해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 "나이가 한 살 많으면 몸값이 3.91% 줄어든다"고 했는데 틀렸다. 로그를 씌운 값의 계수라서 10의 거듭제곱으로 되돌려야 한다. 직접 계산해서 약 0.91배(약 9% 감소)로 고쳤다.
- 느낀 점: 계수 해석을 AI한테 맡겼으면 발표에서 틀린 숫자를 말할 뻔했다.

## 10102 김영희
- 오늘 결정한 것: 나이를 추가한 모델 C를 만들었다. 로그 척도 R² 0.94, MAE 303만 유로로 기준선(1,453만 유로)보다 79% 줄었다.
- AI에게 보낸 프롬프트(원문): 지금 로그 몸값 모델에 나이를 입력 변수로 추가해 줘. 그리고 사용자가 종합 능력치와 나이를 슬라이더로 고르면 예측 몸값을 보여 주는 칸을 모델 결과 탭 아래에 만들어 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 반론으로 "나이 효과가 아니라 로그 변환 효과일 수 있다"고 해서, 로그 없이 나이만 넣은 모델도 확인했다. R² 0.84, MAE 562만 유로로 C보다 컸다. 나이와 로그가 둘 다 필요하다는 것을 확인했다.
- 느낀 점: 나이 하나 넣었을 뿐인데 오차가 3분의 1로 줄어서 놀랐다.

## 10103 이철수
- 오늘 결정한 것: 모델끼리 비교할 때 R²가 아니라 유로 단위 MAE를 기준으로 하기로 바꿨다.
- AI에게 보낸 프롬프트(원문): 로그를 씌운 모델의 R²가 0.62로 원래 모델의 0.67보다 낮았어. 그런데 히스토그램은 로그 쪽이 더 고르게 퍼져. 왜 R²가 낮게 나왔는지 가능한 이유를 알려 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 "두 R²는 서로 다른 척도에서 계산했으니 직접 비교할 수 없다"고 지적했다. 이 지적은 받아들였다. 유로로 되돌려 MAE로 비교하니 B가 766만 유로로 A(857만 유로)보다 작았다. 10차시의 "변환이 항상 답은 아니다" 기록을 "비교는 같은 기준으로 해야 한다"로 고쳤다.
- 느낀 점: 지난 차시에 내린 결론을 우리가 직접 뒤집었는데, 그게 오히려 제일 기억에 남는다.

## 팀 공동: 후보 모델 비교
- 오늘 결정한 것: 최종 입력(종합 능력치, 나이)과 로그 몸값으로 회귀 모델 다섯 개를 같은 분할에서 비교하고, 선형 회귀를 최종 모델로 정했다. MAE는 선형 회귀 303만 유로, XGBoost와 k-NN 263만 유로, 랜덤 포레스트 271만 유로, 결정 트리 621만 유로였다.
- AI에게 보낸 프롬프트(원문): 입력은 종합 능력치와 나이, 예측할 값은 로그를 씌운 몸값으로 그대로 두고 선형 회귀, k-최근접 이웃, 결정 트리, 랜덤 포레스트, XGBoost 다섯 가지 회귀 모델을 같은 훈련·시험 데이터로 비교해 줘. 오차는 유로로 되돌린 평균 절대 오차로 계산하고, 로그 척도 R²와 함께 표로 보여 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 "XGBoost가 가장 좋으니 최종 모델로 쓰자"고 했는데 따르지 않았다. 차이는 40만 유로로 평균 모델과의 차이(1,150만 유로)에 비하면 작고, 우리 질문은 몸값이 무엇으로 설명되는지라서 "능력치 1점당 1.20배, 나이 한 살당 0.91배"를 읽을 수 있는 선형 회귀가 맞다고 판단했다. XGBoost가 더 잘 맞힌다는 수치는 README 표에 그대로 남겼다.
- 느낀 점: 점수가 제일 높은 모델이 우리 질문에 제일 맞는 모델은 아니라는 걸 알았다.
