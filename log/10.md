# 10차시 기록: 로그 변환 시도

## 20203 김도윤
- 오늘 결정한 것: 몸값에 로그를 씌운 모델 B를 만들었다. 로그 척도 R²가 0.62로 모델 A(0.67)보다 낮게 나와서, 일단 "변환이 항상 답은 아니다"라고 기록했다.
- AI에게 보낸 프롬프트(원문): 몸값 분포가 한쪽으로 많이 치우쳐 있어. 몸값에 로그(밑 10)를 씌워서 예측하는 모델을 하나 더 만들고, 원래 모델과 R²를 비교해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 "로그 변환이 성능을 높일 것"이라고 미리 장담했는데 실제 R²는 낮게 나왔다. 기대가 아니라 나온 숫자로 판단하기로 했다. (11차시에 이 비교 자체가 틀렸다는 것을 알게 됐다.)
- 느낀 점: 교과서에서 본 방법이라고 해서 우리 데이터에서도 꼭 좋아지는 건 아니라고 생각했다.

## 20211 박서연
- 오늘 결정한 것: 다음 차시에 나이(age)를 입력 변수로 추가하기로 했다. 6차시 산점도에서 같은 능력치의 위쪽 점들이 어린 선수였다.
- AI에게 보낸 프롬프트(원문): 종합 능력치가 비슷한 선수들 중에서 나이와 몸값이 어떤 관계인지 보여 주는 그래프를 추천해 줘. 능력치 80~85 선수만 골라서 보고 싶어.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 세부 능력치 6개를 모두 넣자고 했는데 버렸다. 변수를 한꺼번에 많이 넣으면 무엇이 효과를 냈는지 설명할 수 없다. 나이 하나만 더하기로 했다.
- 느낀 점: 게임하면서 느꼈던 "유망주가 비싸다"를 드디어 데이터로 확인해 볼 수 있게 됐다.

## 20219 이준호
- 오늘 결정한 것: 앱의 몸값 히스토그램에 "원래 값 / 로그 값" 전환 버튼을 넣었다. 왜도가 2.80에서 0.36으로 줄었다.
- AI에게 보낸 프롬프트(원문): 몸값 히스토그램을 원래 금액과 로그 값 두 가지로 바꿔 볼 수 있게 선택 버튼을 넣어 줘. 로그 값 그래프의 축 이름에는 7이 1,000만 유로, 8이 1억 유로라는 설명을 붙여 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 그래프 축 자체를 로그 눈금으로 바꿨는데 막대 폭이 이상하게 나와서, 값을 로그로 바꾼 뒤 보통 히스토그램으로 그리도록 다시 요청했다.
- 느낀 점: 로그를 씌우니까 한쪽에 몰려 있던 막대가 가운데로 퍼져서 신기했다.
