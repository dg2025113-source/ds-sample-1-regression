# 3차시 기록: 데이터 판정·선생님 승인

## 10101 홍길동
- 오늘 결정한 것: 데이터를 세 가지 물음(충분한가·적합한가·윤리적인가)으로 판정하고 선생님께 승인을 받았다.
- AI에게 보낸 프롬프트(원문): 선수 800명의 게임 능력치와 몸값이 담긴 데이터로 "몸값은 능력치로 설명되는가"를 분석하려고 해. 이 데이터가 이 질문에 충분한지, 적합한지, 법적·윤리적으로 문제가 없는지 각각 판단해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI는 "실존 인물의 데이터라 개인 정보 문제가 있다"고 했는데 그대로 받지 않았다. 게임에 공개된 능력치이고 연락처나 사생활 정보는 없다는 점을 적어 선생님께 확인받았고, 승인을 받았다.
- 느낀 점: 개인 단위 정보의 뜻을 처음으로 제대로 생각해 봤다.

## 10102 김영희
- 오늘 결정한 것: 팀 저장소를 공개로 만들고 README의 질문과 데이터 칸을 채웠다.
- AI에게 보낸 프롬프트(원문): 깃허브에 팀 저장소를 처음 만들어. README, data 폴더, code 폴더, log 폴더를 만드는 순서를 웹 화면 기준으로 알려 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 터미널 명령어로 설명해서 다시 물었다. 학교 컴퓨터에서는 웹 화면으로 하는 게 편해서 그 방법만 사용했다.
- 느낀 점: 저장소를 만드니까 진짜 팀 프로젝트를 시작한 느낌이 들었다.

## 10103 이철수
- 오늘 결정한 것: data 폴더에 csv를 올리고 출처.md에 주소, 받은 날짜, 행 수를 적었다.
- AI에게 보낸 프롬프트(원문): 데이터 출처 문서에 꼭 들어가야 할 항목을 알려 줘. 고등학생 팀 프로젝트용이야.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 제안한 "라이선스 전문 붙여 넣기"는 뺐다. 라이선스 이름과 원래 출처 주소만 적어도 확인할 수 있다고 판단했다.
- 느낀 점: 원래 출처를 따라가 보니 이 데이터가 게임사 공식 자료가 아니라는 것도 알게 됐다.
