- 출처: A dataset of infrared (ATR-FTIR) spectra for textile fibres of natural and man-made origin. Mendeley Data에 공개된 섬유 적외선 스펙트럼 데이터입니다.
- 데이터 주소: https://data.mendeley.com/datasets/rx3fjgz96x/3
- DOI: https://doi.org/10.17632/rx3fjgz96x.3
- 라이선스: CC BY 4.0. 데이터를 이용하거나 재배포할 때는 원 출처와 저작자 정보를 표시해야 합니다. 자세한 조건은 데이터 페이지의 라이선스를 확인합니다.
- 공개된 데이터 설명: 섬유 시료 137개에서 얻은 스펙트럼 160개를 포함하며, 데이터 설명에는 26개의 섬유 세부 종류가 소개되어 있습니다.
- 이번 분석 파일: 05_feature_matrix_preprocessed_als_snv_sgd2.csv
- 현재 확인한 파일 정보: 160개 측정 행이 있으며, Type, Subtype, Spectrum_ID, Sample_ID, Replica, Origin 등의 식별·분류 열과 파수에 따른 스펙트럼 측정값이 들어 있습니다. 이 파일에서는 Type의 서로 다른 값이 10개, Subtype의 서로 다른 값이 31개로 확인되었습니다. 공개 데이터 설명의 분류 개수와 파일에서 확인한 개수가 다르므로, 실제 분석에 사용할 파일의 값과 데이터 설명을 함께 확인해야 합니다.
- 사용할 열: 입력값은 파수에 따른 스펙트럼 측정값, 예측할 값은 Subtype입니다. Sample_ID는 같은 시료에서 반복 측정한 데이터가 학습용과 평가용에 나뉘지 않도록 데이터를 나눌 때 확인용으로 사용합니다.
- 개인정보 확인: 이 데이터는 섬유 시료와 측정값을 중심으로 구성된 자료입니다. 분석에 사용하기 전에 파일에 사람의 이름, 연락처, 주소 등 개인을 식별할 수 있는 정보가 포함되어 있지 않은지 확인합니다.
데이터에서 확인할 점과 전처리 판단
- Subtype에 어떤 종류가 얼마나 들어 있는지 확인합니다. 종류별 데이터 수가 크게 다르면 정확도만으로 모델 성능을 판단하기 어려울 수 있습니다.
- 스펙트럼 측정값에 비어 있는 값이나 숫자가 아닌 값이 있는지 확인합니다. 문제가 있으면 원인을 확인한 뒤 처리하고, 이유 없이 평균값으로 채우지 않습니다.
- Spectrum_ID, Sample_ID, Replica처럼 섬유 종류 자체의 스펙트럼 특징이 아닌 열은 기본 입력값에서 제외합니다. 특히 Sample_ID는 같은 시료에서 나온 측정값을 확인하는 데 사용합니다.
- 같은 시료에서 측정한 스펙트럼이 학습 데이터와 시험 데이터에 동시에 들어가면 모델의 성능이 실제보다 높게 나올 수 있습니다. 따라서 가능한 경우 Sample_ID를 기준으로 시료를 나누어 평가합니다.
- 이 파일은 전처리된 스펙트럼 데이터입니다. 원본 스펙트럼과 다른 전처리 파일을 함께 사용할 때는 같은 데이터를 중복해서 학습하거나 평가하지 않도록 주의합니다.

분석 과정
1. 데이터 수집: Mendeley Data에서 공개한 섬유 적외선 스펙트럼 데이터 중 05_feature_matrix_preprocessed_als_snv_sgd2.csv 파일을 사용합니다.
2. 변수 선택: 입력값은 파수에 따른 스펙트럼 측정값으로 하고, 예측할 값은 Subtype으로 정합니다.
3. 데이터 확인: 행과 열의 수, 섬유 종류별 데이터 수, 결측값, 중복값을 확인합니다.
4. 전처리: Subtype과 스펙트럼 측정값을 분리하고, 숫자가 아닌 값이나 결측값이 있는지 확인합니다. Spectrum_ID, Sample_ID, Replica, Type, Origin은 기본 입력값에서 제외합니다.
5. 데이터 분할: 학습용 데이터와 시험용 데이터를 나눕니다. 같은 Sample_ID의 스펙트럼이 두 데이터에 동시에 들어가지 않도록 나누는 방법을 우선 고려합니다.
6. 기준 모델 설정: 모든 데이터를 가장 많이 등장하는 섬유 종류라고 예측하는 단순 기준 모델을 만들어 비교 기준으로 사용합니다.
7. 후보 모델 비교: 예를 들어 k-NN, 결정 트리, 랜덤 포레스트 등의 분류 모델을 같은 데이터 분할에서 비교합니다. 실제 사용할 모델은 실행 결과와 설명 가능성을 고려해 정합니다.
8. 평가: 정확도와 혼동 행렬을 확인합니다. 섬유 종류별 데이터 수가 불균형하면 macro F1-score와 balanced accuracy도 함께 확인합니다.
9. 결과 해석: 어떤 섬유 종류를 잘 구분했고 어떤 종류를 자주 헷갈렸는지 살펴봅니다.
10. 한계 점검: 데이터 수가 많지 않고 같은 시료에서 반복 측정한 값이 포함되어 있다는 점, 실제 범죄 현장 시료와 실험실 데이터가 다를 수 있다는 점을 고려합니다.

한계
- 측정 데이터는 160개이고 실제 시료는 137개이므로, 데이터 규모가 크다고 보기 어렵습니다.
- 한 시료에서 여러 스펙트럼을 측정했을 수 있으므로, 데이터를 무작위로 나누면 같은 시료의 특징이 학습과 시험에 동시에 들어가 결과가 실제보다 좋게 나올 수 있습니다.
- 데이터에 포함된 섬유 종류와 측정 조건에 대해서만 성능을 확인할 수 있습니다. 데이터에 없는 섬유나 실제 범죄 현장의 오염된 섬유에도 같은 성능이 나온다고 보장할 수 없습니다.
- 스펙트럼으로 종류를 구분할 수 있어도, 그것만으로 특정 사람이나 범죄를 확정할 수는 없습니다. 실제 과학수사에서는 다른 증거와 전문가의 판단도 필요합니다.
