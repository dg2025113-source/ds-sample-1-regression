# 데이터 출처

- 파일: `eafc25_players.csv`
- 받은 곳: https://raw.githubusercontent.com/greatsong/modudata/main/data/eafc25_players.csv
- 받은 날짜: 2026-10-15
- 원래 출처: modudata 설명에 따르면 GitHub `mzafram2001/ea-fc` 저장소의 `dataset_ea_fc_25.csv`(MIT 라이선스)입니다. 게임사가 공식 배포한 데이터는 아닙니다.
- 내용: EA SPORTS FC 25 게임의 선수 능력치(2024-25 시즌). 원본 18,507명 가운데 골키퍼를 빼고 종합 능력치 상위 800명을 고른 사본입니다.
- 크기: 800행, 14열, 인코딩 UTF-8

## 열 설명

| 열 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| name | 선수 이름(짧은 표기) | 그래프에서 선수 확인 |
| long_name | 선수 이름(전체) | 사용하지 않음 |
| positions | 포지션. "RM,RW"처럼 쉼표로 이어 적음 | 잔차 확인(첫 번째 포지션) |
| club | 소속 구단. 8명은 빈 칸 | 몸값 0인 선수 확인 |
| overall | 종합 능력치(77~91) | 입력 변수 |
| pace, shooting, passing, dribbling, defending, physic | 세부 능력치 6개 | 사용하지 않음 |
| value_eur | 게임 안의 몸값(유로). 0인 선수 9명 | 예측할 값 |
| age | 나이 | 입력 변수(11차시부터) |
| height_cm | 키(cm) | 사용하지 않음 |
