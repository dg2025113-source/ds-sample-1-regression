# 데이터 출처

- 파일: `eafc25_players.csv`
- 출처(1차): EA SPORTS FC 25 선수 능력치(EA Sports, 2024-25 시즌). 공개 페이지(sofifa.com)를 정리한 GitHub mzafram2001/ea-fc `dataset_ea_fc_25.csv`(MIT 라이선스), 2026-10-15 접근(이 저장소는 2026-10-16 현재 삭제되어 접속할 수 없습니다). 게임사가 공식 배포한 데이터가 아닙니다. 현재 확인할 수 있는 사본은 아래 수업용 사본뿐입니다.
- 이용 조건: 정리본 저장소는 MIT 라이선스입니다. 공식 대회에 출품할 때는 데이터 제공처(sofifa.com·EA Sports)의 이용 약관을 확인해야 합니다.
- 수업용 사본 경로: https://raw.githubusercontent.com/greatsong/modudata/main/data/eafc25_players.csv (2026-10-15 받음)
- 내용: EA SPORTS FC 25 게임의 선수 능력치(2024-25 시즌). 원본 18,507명 가운데 골키퍼를 빼고 종합 능력치 상위 800명을 고른 사본입니다.
- 크기: 800행, 14열, 인코딩 UTF-8

## 열 설명

| 열 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| name | 선수 이름(짧은 표기) | 그래프에서 선수 확인 |
| long_name | 선수 이름(전체) | 사용하지 않음 |
| positions | 포지션. "RM,RW"처럼 쉼표로 이어 적음 | 잔차 확인(첫 번째 포지션) |
| club | 소속 구단. 8명은 빈 칸 | 몸값 0인 선수 확인 |
| overall | 종합 능력치(77~91) | 입력 변수 |
| pace, shooting, passing, dribbling, defending, physic | 세부 능력치 6개 | 사용하지 않음 |
| value_eur | 게임 안의 몸값(유로). 0인 선수 9명 | 예측할 값 |
| age | 나이 | 입력 변수 |
| height_cm | 키(cm) | 사용하지 않음 |
